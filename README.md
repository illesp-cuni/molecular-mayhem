# Molecular Mayhem

A browser-based molecular physics puzzle game inspired by slingshot games. Use charged, adhesive, repulsive and impact beads to selectively extract targets from molecular assemblies.

## Play

Open `index.html` in a modern browser. No dependencies or build step required.

## Current version: 0.4 — Field Lab

18 levels, interaction fields, trajectory prediction, selective extraction, protected particles and locally saved campaign progress.

## Development

The current prototype is self-contained HTML, CSS and JavaScript. Physics is deliberately tuned for gameplay rather than quantitative molecular simulation.
